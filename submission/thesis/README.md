## 实现口径

本仓库 **`main` 分支**即为论文第 4～6 章描述的工程实现：

- **架构**：React + FastAPI 前后端分离（§5.5）
- **涡旋**：OW 伪标签 + YOLOv8-seg，在线推理 **3 通道** ADT/U/V（§5.3）
- **风浪**：共享编码器双头 LSTM + 残差异常检测 + DTW 历史过程弱关联（§5.4）
- **数据**：NetCDF 变量映射、懒加载时空裁剪、离线 NC 批处理与可选实时接入（§5.2）
- **界面**：顶栏四入口——监测总览 / 涡旋分析 / 风浪分析 / 报告管理（§4.5）
