### 3.0 与本轮优化直接相关的实测结论（摘要）

以下为 **扩展指标**（归一化空间 MAE/RMSE、Pearson、`Skill = 1 - MSE_model/MSE_persistence`，persistence = 输入末帧铺满预报窗）在 **val / test** 上的 **共性**（两套切分同向）：

| 观测 | val / test 共性 |
| --- | --- |
| 全通道平均 **MAE、RMSE** | L0 **略优于** L2（差距小但在两侧一致） |
| 全通道平均 **Pearson** | L0 **略优于** L2 |
| 全通道平均 **Skill** | **仍为负**，且 **L2 略高于 L0**（负得更少） |
| **分通道** | **u、v**：L0 **稳定略优**；**temp、sal**：L0 **略弱于** L2 |

**对 §3 的含义**：

1. 存在清晰的 **通道间取舍**，下一轮调参应以 **收回温盐 + 不毁掉 u/v 增益** 为显式目标之一。
2. **Skill 为负**：相对 persistence，两版模型都不算强；sal 等分项 Skill 极负会 **压低平均 Skill**，与 «u/v、Pearson 变好» 可同时成立——优化目标需分项监控，不能只盯一项。
3. **答辩/材料必须先锁定「主指标」**：例如以 **误差类（MAE/RMSE）+ Pearson** 为主，或以 **Skill** 亦为硬门槛；否则 §3.4 无法一刀切判定「优于基线」。

产物归档建议：`submission/tables/hydro_l0_vs_baseline_val.{md,csv}`、`submission/tables/hydro_l0_vs_baseline_test.{md,csv}`、`outputs/cloud/hydro_compare_*_summary.json`（**val 与 test 输出文件名分班**，避免互相覆盖）。

### 3.1 低成本（先做，必须成组对照）

**本轮建议优先顺序**（固定 seed；**每轮仅改 1～2 个变量**）：

1. **损失权重微调（针对 temp、sal 略弱于 L2）**
   - `loss.eos_constraint.weight`: `0.1 → 0.03 / 0.05` 做网格；
   - `mae_weight`: 微调或短时设 `0` 做 **对照**，观察温盐误差是否回流、**u/v 是否明显受损**。
2. **训练稳定性 — 学习率**
   - 网格：`1e-4`、`7e-5`、`5e-5`；在增益胶着时 **低成本试探**「温盐-u/v」折中。
3. **AttnRes 复杂度（假说：容量/正则与各通道难度不匹配时易出现通道取舍）**
   - `attn_res.num_blocks: 8 → 6 / 4`；
   - 调整 `attn_res.reduction`，降低过拟合与显存压力；
   - 必须与 **(1)** 分列实验，便于归因。

禁止：一次改多项超参却将效果笼统归因于「L0 结构」。

---

### 3.2 中成本（在 §3.1 有明确折中结论后再上）

结合 **«L2 在温盐与平均 Skill 略占优；L0 在 u/v 与 Pearson 略占优»** 的实测：

1. **分阶段训练：L2 收敛 → 加载为初值后在 L0 配置下微调**（**本轮最优先尝试的中成本路径**）
   - 动机：保住 L2 在 **temp、sal** 上的表现，再吸收 L0 结构对 **u、v** 的收益；
   - 必记日志：初始权重路径、`hydro_hycom_l2`/`l0` 与 `train` 段差异、微调 epoch/lr。
2. **通道加权损失（重点 u/v）—— 慎用**
   - u/v 已略优，**权过大可能加剧温盐变差**；
   - 建议：**加权 + 温盐分项监控/保底**，与 **不加权**、**L2→L0** 做 **三方对照** 后再决定是否进主交付。

---

### 3.3 高成本（本轮默认不进主线；触发条件）

仅在 **§3.1～3.2 多组对照后**仍出现：**sal/temp 长期弱于 L2**，且 **Skill 或物理尺度误差** 无法用损失与学习日程解释时，再评估：

- 预处理策略迭代（**分通道归一化、鲁棒缩放**等）并 **全量重跑** processed；
- 更强物理约束（须与 **反标准化与公式口径** 逐项对齐）。

---

### 3.4 方案筛选规则（与实测对齐后的可操作版）

1. **先写死对外主指标集合**（多指标并列时须写明权重或门槛）：
   - **口径 A**：以 **全通道平均 MAE、RMSE + Pearson**，并单列 **u、v 分量** ⇒ 当前 L0 在 val/test **一致略优于** L2，§3.1 的目标是 **拉大优势并修复温盐**。
   - **口径 B**：以 **Skill（相对 persistence）** 亦为硬门槛 ⇒ 当前 L0 **平均 Skill 未优于 L2**，**不得**宣称「已对基线全面占优」；须 **针对 Skill（含温盐分项）** 再迭代或对 persistence 类比口径做评审后再下结论。
2. **工程规则**：候选方案须在 **val 与 test 上相对 L2、与主指标同向**，方可进主交付；仅单侧改善视为 **未过关**。
3. **增益微弱且复杂度高**：只保留探索记录，**不替代 L2 主交付位**。
