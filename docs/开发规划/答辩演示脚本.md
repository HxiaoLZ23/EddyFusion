## 2. 演示流程（约 8～12 分钟）

### 步骤 1 · 监测总览 — 数据接入与裁剪（§5.2）

1. 顶栏进入 **监测总览**，数据源选 **离线 NC 上传**。
2. 左侧 **任务配置**：上传含 `time` 维的 NetCDF（需含 ADT/U/V；风浪演示另需 u10/有效波高）。
3. 点击 **探测元数据**，填写时间索引范围与 ROI，**应用裁剪**。
4. 口述：xarray 懒加载 + 变量映射（`config/nc_variable_map.yaml`）+ 子集写出。

**截图点**：左栏 TaskConfigPanel + 元数据反馈。

### 步骤 2 · 涡旋分析 — 3ch YOLO（§5.3）

1. 快捷入口或顶栏进入 **涡旋分析**（保持离线数据源）。
2. 左侧确认 NC 已选；输入 `time_index`，点击 **加载预览帧**。
3. 中央展示 YOLO mask 叠加场图；右侧 **检测统计表**（面积、质心、置信度）。
4. 返回监测总览，观察 **双路 MP4**（底图先播 → YOLO 标注路补齐）。

**截图点**：`/eddy` 左-中-右布局；双路 MP4 时间轴。

**话术**：论文主口径为 3ch；7ch 增通道消融为附录负结果，系统 UI 不提供。

### 步骤 3 · 风浪分析 — LSTM + 异常 + DTW（§5.4～§5.5.4）

1. 顶栏 **风浪分析**，左侧任务类型选风浪。
2. 点击 **运行风浪预测**：中央双曲线 + 黄/橙/红异常色带；右侧异常等级与 **DTW Top-K** 卡片。
3. 点击 **导出结构化报告**：自动下载 Markdown 并归档至报告管理。

**截图点**：预测曲线异常高亮；Top-K 与等级同屏。

### 步骤 4 · 报告管理 — 归档与再导出（§5.5.5）

1. 顶栏 **报告管理**。
2. **已保存报告** 列表选中一条 → 右侧预览全文。
3. 演示 **下载 Markdown** 与 **再导出（重跑 API）**。
4. 切换 **会话任务记录**，展示当前会话涡旋/风浪任务摘要。

**截图点**：报告列表 + Markdown 预览。

## 3. 增强能力（G15～G16，可选口述）

- **准实时**：监测总览切「准实时」→ 查看连接器状态（`GET /api/realtime/status`）→ 拉取 latest；新文件到达会提示「检测到新文件」。
- **异步任务**：涡旋双 MP4、风浪预测经 `POST /api/jobs` 提交，页面显示进度条；大 NC 不会长时间阻塞 HTTP。
- **性能论据**：`submission/tables/nc_lazy_subset_benchmark.md` — 384MB NC 的 `probe_nc_meta` 峰值约 0.2MB，整库物化约 666MB。

## 4. 功能测试核对表（§6.3）

| 编号 | 测试项 | 接口/方法 | 预期结果 |
|------|--------|-----------|----------|
| T1 | NC 元数据探测 | `GET /api/preprocess/meta` | `time_len`、`variables`、`variable_map` |
| T2 | 时空裁剪 | `POST /api/preprocess/subset` | 子集写入 `app/data/nc_uploads/subsets/` |
| T3 | 涡旋单帧预览 | `POST /api/eddy/preview-frame` | PNG data URL + `stats_rows`（YOLO/ADT 降级） |
| T4 | 涡旋双路 MP4 | `POST /api/jobs`（`eddy_dual_mp4`） | 分阶段至 `done`，双路 MP4 可访问 |
| T5 | 风浪预测（同步） | `POST /api/windwave/forecast` | 曲线 + `anomaly_segments` + Top-K |
| T6 | 结构化报告归档 | `structured` → `save` → `history` | 可列表、按 id 读取 Markdown |
| T7 | 风浪预测（异步） | `POST /api/jobs`（`windwave_forecast`） | job 至 `done`，含 `result.series` |
| T8 | 准实时连接器 | `GET /api/realtime/status` | 连接器字段完整；前端见 `/monitor?source=realtime` |

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| 前端无法连 API | 确认 `run_web_api.ps1` 已启动；开发模式可不设 `VITE_API_BASE`（走 Vite 代理） |
| preview-frame 显示 ADT 降级 | 涡旋权重未就位；检查 `outputs/eddy_v6_b0_fair/` |
| 风浪预测失败 | NC 缺 u10/v10 或 swh；换含风浪变量的文件 |
| Top-K 为空 | 运行 `seed_typhoon_kb_demo.py` 或完整 `run_typhoon_kb.ps1` |
| 报告列表为空 | 需先在风浪页点击「导出结构化报告」 |
