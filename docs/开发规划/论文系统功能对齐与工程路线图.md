# 论文系统功能对齐与工程路线图

> **状态（2026-06）**：**本仓库 `main` 分支已与毕业论文终稿对齐**，可作为答辩演示与复现基线。  
> **终稿**：`9-3.毕业论文_黄柏霖_软件222_202201050577.docx`（本地归档，不入库）；Markdown 镜像见 `submission/thesis/`。  
> **论文实现口径（§3.1.3、§5.1、§5.5）**：**React + FastAPI** 前后端分离；**不含水文预测模块**。  
> **论文算法口径**：涡旋 **ADT/U/V 三通道 + YOLOv8-seg**；风浪 **双头 LSTM + 异常预警 + DTW Top-K**。  
> **口径变更（2026-06）**：7ch 已从论文主叙事移除；E6 增通道消融为负结果附录，推理侧固定 3ch。  
> **本路线图范围**：仅 `web/` + `web_api/` + `src/` 中与论文模块相关的部分。**Streamlit `app/` 暂不纳入**（仓库保留，不阻塞论文系统章）。**水文 `src/hydro/` 及 React 水文区块不在论文范围**，列为仓库存量，默认 `PAPER_ALIGN_UI` 关闭。

## 1. 论文要求的功能全景

### 1.1 四层架构（§4.2）

| 层 | 论文职责 |
|----|----------|
| 数据资源层 | 再分析/遥感 NC、历史台风事件库 |
| 数据处理层 | NetCDF 解析、时空 ROI/时间切片、变量映射、缺失值、动力学特征（训练期 OW 伪标签等） |
| 智能分析层 | **涡旋** YOLOv8-seg（**3ch**）；**风浪** 双头 LSTM + 异常检测 + DTW |
| 应用展示层 | 上传与任务配置、场图/曲线、统计与**结构化报告导出** |

### 1.2 四大功能模块（§4.3）

1. **多源数据处理与物理特征构造**（§3.2.1、§5.2）  
2. **海洋中尺度涡旋智能识别**（§3.2.2、§5.3）  
3. **风浪异常预测与关联分析**（§3.2.3、§5.4）  
4. **可视化交互与预警管理**（§3.2.4、§5.5）

**全文无「水文」「ConvLSTM」「温盐预测」等表述。** SST 等在论文中仅为多源变量示例或可选演示字段，不构成独立分析模块。

### 1.3 界面与交互（§4.5、§5.5.1）— 论文原意

**顶栏导航**（功能入口，非数据源模式）：

- 海洋环境监测（总览/入口）
- 涡旋识别分析
- 风浪预测分析
- 报告管理

**单页分区布局**（按任务切换内容，结构一致）：

| 区域 | 职责 |
|------|------|
| **左侧** | NetCDF 上传；**分析时间范围**；**研究区域 ROI**；**任务类型**（涡旋 / 风浪） |
| **中央** | 标量场伪彩（ADT 等）；**流场矢量箭头**；涡旋 **mask 叠加**；或风浪 **预测曲线 + 异常高亮** |
| **右侧** | 涡旋统计表 / 风浪预测摘要 / **异常等级** / **DTW Top-K** / **报告生成与导出** |

辅助能力：**时间轴**切换时步、图层开关、缩放、区域查询（§3.2.4）。

### 1.4 非功能需求（§3.3）

- xarray **懒加载**、分块、内存控制  
- **训练与在线推理分离**（仅加载权重）  
- REST/JSON 模块化 API，算法可替换  

### 1.5 实现章节硬交付（§5）

- 表 5-2 变量映射 → 统一 schema  
- 时空裁剪（图 5-3/5-4）、缺失值掩膜、Min-Max 归一化  
- OW 规则伪标签（**训练**）；推理输入 **仅 3ch**（§5.3.1）  
- YOLO Pipeline → NMS → mask → **JSON 统计**（§5.3.4）  
- LSTM 滑动窗口 + 双头 + Z-score（§5.4.1～5.4.2）  
- DTW Top-K + 黄/橙/红预警（§5.4.3～5.4.4）  
- React 地图/曲线 + **结构化分析报告导出**（§5.5.5）  
- 工程目录：`web/`、`web_api/`、`src/`（与仓库一致）

### 2.2 React 前端（`web/`）

| 论文要求 | 现状 | 偏差说明 |
|----------|------|----------|
| 顶栏：监测 / 涡旋 / 风浪 / 报告 | 🟡 | 现为 **离线 / 实时 / 台风查询**（数据源模式导航，非论文四入口） |

| 水文区块 | — | **论文无**；`SHOW_HYDRO_UI` 时为仓内扩展，本路线 **不启用、不改造** |

### 2.3 布局对照（重要）

```
论文 §4.5（任务页）          当前 OceanDashboard（仓内）
┌────┬────────┬────┐        ┌──────────┬─────────┐
│上传│  中央   │统计│        │  涡旋    │水文/台风│
│配置│ 场图+mask│报告│   ≠    │ （整高） │─────────│
│    │ 或曲线  │TopK│        │          │  风浪   │
└────┴────────┴────┘        └──────────┴─────────┘
```

论文是 **左-中-右 + 顶栏四功能**；当前是 **左涡旋 + 右上下分栏（含非论文水文）**。对齐工作需要 **重构 React 信息架构**，而非在现有三栏上叠功能。

## 8. 不可更改与风险

- **不可改**：`config` 的 `level`、`run_eval_all` 指标链、3ch 权重 `outputs/eddy_cloud_fair`；表 6-1 mAP 与仓库评测一致。
