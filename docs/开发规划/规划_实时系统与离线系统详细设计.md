## 1. 总目标

| 系统 | 布局与三区块行为 | 与单模块页差异 |
|------|------------------|----------------|
| **离线系统** | 同屏：**左涡旋、右上水文、右下风浪**；压缩页眉与上传区占比 | 各区块交互与展示按本文 §3～§5 |
| **实时系统** | **与离线系统布局与三区块行为一致** | **仅数据源不同**：准实时 NetCDF / 最新格点产品（**接入占位**）对比离线的「本地上传文件」 |

## 2. 页面整体布局（离线 / 实时共用）

### 2.1 栅格结构

```
┌─────────────────────────────────────────────────────────────┐
│ 紧凑条：标题一行 + 数据源控件一行（上传 / 准实时占位状态）    │
├──────────────────┬──────────────────────────────────────────┤
│                  │  水文区块（右上）                          │
│   涡旋区块       │  ─────────────────                         │
│   （左侧整高）   │  风浪区块（右下）                          │
│                  │                                          │
└──────────────────┴──────────────────────────────────────────┘
```

- **左侧列**：宽度约占 38%～45%（可配置），**纵向贯穿**，专用于涡旋双画面 + 时间戳条 + 视频控制。
- **右侧列**：上下二等分或按黄金比例分割；**上 = 水文**，**下 = 风浪**。
- **紧凑条**：`st.columns` 或单行 `st.expander` 默认折叠「上传与高级选项」；主标题 `st.title` 改为 `st.markdown("### …")` 或单行加粗，避免占掉半屏。

### 2.2 数据源行（离线 vs 实时）

| 模式 | 控件 | 行为 |
|------|------|------|
| 离线 | 多文件 `file_uploader` 收起到 expander；主区仅保留「已选 N 个文件」徽标 + 「管理文件」 | 与现有 `nc_ingest_service` 一致 |
| 实时 | **占位**：连接器 URI / 轮询目录 /「拉取 latest」按钮；状态灯（未连接 / 缓冲中 / 就绪） | 抽象接口 `fetch_latest_nc(spec) -> Path | Dataset`（见上位规划 §2.1）；首版可 **模拟**：定时复制指定路径 NC 到缓存 |

### 2.3 会话与任务 ID

- 建议统一 `offline_dashboard_state` / `realtime_dashboard_state` 前缀，内含：`nc_paths[]`、`eddy_video_path`、`hydro_materialize_meta`、`windwave_summary_dict` 等，避免与单模块页 `eddy_last_result` 键冲突时可做**只读镜像**或显式「同步到风浪工作台」按钮。

## 3. 涡旋区块（与单模块差异）

### 3.1 功能需求

| # | 需求 | 说明 |
|---|------|------|
| 1 | **生成视频后自动播放** | 全 NC 推理管线产出 MP4（或内存字节）后，主区 `st.video` 或 HTML `<video autoplay>` 立即播放，无需用户二次点击 |
| 2 | **时间戳叠加** | 若 NC 含可解析时间坐标：在**播放画面上方**（非编码进视频内亦可）显示与**当前帧**一致的文本时间戳；无时间维则隐藏或显示 `T+index` |
| 3 | **双画面同步** | **上**：底图 / 流场可视化，**无** YOLO 检测框；**下**：同帧 **带** 识别框/掩码边线。两路 **同一时刻、同一 FPS 时间轴** 同步（暂停/拖动进度条时两路一致） |
| 4 | **整 NC 视频化** | 对 NC 内**全部**（或可配置）时间索引逐帧合成一条视频；**输出 FPS = 1**（固定常量，与单模块页可调 FPS 解耦，避免误解） |

### 3.2 实现要点（工程）

- **离线渲染管线**：复用 `EddyDemoService` / `infer_netcdf_frame` 的抽帧与绘制逻辑，扩展为批处理循环 `for t in range(T)`，写出两路像素缓冲（无框 / 有框），再用 `ffmpeg` 或现有 `src/eddy/mp4_browser_safe.py` 合成 H.264；或单 pass 编码时交替写两轨道（若需单文件双轨，需评估播放器兼容性；**更稳妥为两个 MP4 + 双 `<video>` 用 JS 锁同一 `currentTime`**）。
- **时间戳**：从 `xarray` / `infer_typhoon_link` 同类逻辑读取 `time` 坐标，与 `time_index` 对齐格式化 `YYYY-MM-DD HH:MM`。
- **自动播放**：Streamlit `st.video(url_or_bytes, autoplay=True)`（版本需确认）；若浏览器策略禁止自动有声播放，视频应 **muted**。
- **性能**：整 NC、FPS=1 仍可能帧数多；需后台任务或进度条、`st.status`，避免阻塞主线程导致会话掉线。

### 3.3 验收标准

- 打开含时间维的命题方样例 NC，生成结束后双画面自动播放，时间戳与帧同步变化，FPS 导出为 1。
- 无时间维 NC：双画面仍同步，时间戳区域显示步进索引或隐藏（产品需二选一并写死）。

## 4. 水文区块（与单模块差异）

### 4.1 功能需求

| # | 需求 | 说明 |
|---|------|------|
| 1 | **仅曲线图** | 不展示热力图 `imshow` 三宫格；仅 **区域均值曲线**（与单模块 `curve_data` 同源） |
| 2 | **轮换** | 多要素时 **每 2 秒**切换当前展示的要素曲线 |
| 3 | **悬停暂停** | 鼠标悬停在图表上时，**暂停**要素轮换；移出后继续 |
| 4 | **数据不足** | 当缓冲区时间步未达 `T_need` 或无法构建滑窗时：图表区域 **虚化**（CSS `opacity` + 模糊或灰色蒙层）+ 文案 **「数据不足，等待中」** |

### 4.2 实现要点（工程）

- **轮换定时器**：Streamlit 全页 rerun 驱动可用 `st.fragment(run_every=2)`（若版本支持）或 `time.sleep`+**不推荐**；更稳妥为 **`st.plotly_chart` + `dcc.Interval` 式逻辑** 需 `streamlit-plotly-events` 或 **自定义 `components.html`** 内嵌 Plotly，在浏览器端做 2s `setInterval` 切换 trace，`plotly_hover` 时 `clearInterval`。
- **悬停暂停**：原生 `st.line_chart` **无法**可靠监听 hover；本设计**建议水文同屏页强制 Plotly**（与单模块「深度页」分离）。
- **虚化**：`st.container` 外包一层 `st.markdown(..., unsafe_allow_html=True)` 固定高度 + 绝对定位蒙层，或 Plotly `layout.shapes` 半透明矩形。

### 4.3 验收标准

- 至少 3 个要素时，肉眼可见每 2 秒切换；悬停曲线 2s 内不切换；数据不足时仅见蒙层与提示文案。

## 5. 风浪区块（与单模块差异）

### 5.1 功能需求

| # | 需求 | 说明 |
|---|------|------|
| 1 | **醒目等级** | 文本框**上方**单独一行（大字 / pill 标签）显示 **当前异常等级**（如 low / mid / high，与现有 `run_detect` 或演示分级一致） |
| 2 | **等级配色** | 不同等级 **不同背景色与文字色**（需满足 WCAG 对比度下限，色板写入 `app/config` 或 CSS 变量） |
| 3 | **结构化文本框** | 固定模板多行文本，例如：  
   `异常等级: …`  
   `异常指数: …`  
   `风速残差: …`  
   `波高残差: …`  
   `建议: …`  
   缺数据时对应项显示 `-` 或「未接入」 |

### 5.2 数据与后端

- 与 `eddy_last_result` / 同屏内临时 `windwave_series` 对齐；调用现有 `run_detect` 或轻量 `compute_anomaly_assessment` 输出字段映射到上述行。
- 同屏页 **不强制** 展开台风表格与 LLM（迁至 **Level 1 风浪二级页**，见 §6.3）。

### 5.3 验收标准

- 等级变更时颜色立即切换；文本与后端分级一致。

## 6. Level 1（评估后实现）：二级子页面

> **定位**：在**不拆除** §2 同屏三区块的前提下，通过 **悬停提示 + 点击** 进入某一区块的「加深」视图；**其余区块折叠**；过程要求 **流畅动画**。  
> **评审结论占位**：实现前需评估 **Streamlit 动画能力边界**（见 §8）。

### 6.1 通用交互

| 步骤 | 行为 |
|------|------|
| 悬停 | 对应区块边框高亮 / 轻微阴影 / 角标「点击进入详情」，**不改变**当前区块内正在播放的内容（尤其涡旋双视频不停） |
| 点击 | 进入该区块 **Level 1 模式**；其他两区块 **折叠**为窄条或图标条（保留「展开回去」入口） |
| 动画 | 目标：300～400ms 缓动；可选技术：CSS `transition`（`components.html` 包裹）、或迁移该屏到 **Plotly Dash / 独立前端** 再做路由动画 |

### 6.2 涡旋二级页

| 项 | 说明 |
|----|------|
| 布局策略 | **主区双视频保持不动、继续播放**；从**右侧或左侧滑出**抽屉面板（宽度 320～400px） |
| 抽屉内容 | **历史表**：最近 **10** 条，列：`time`（或时间戳）、`peak_score`、`status`（成功/失败/进行中） |
| 数据来源 | 本会话内队列：每次整 NC 生成任务完成时 `append`；持久化可选 `st.session_state` 或本地 sqlite |

### 6.3 水文二级页

| 项 | 说明 |
|----|------|
| 布局 | **重新布局**：**所有要素曲线** 同时展示（网格子图或纵向多 `plotly_chart`） |
| 编辑能力 | **缓冲区**：与单模块 `hydro_nc_buffer` 行为一致的可视化列表与追加/删除；**暂存区**：用户勾选「待合并」文件列表，再一键「推入缓冲区」或「清空暂存」 |

### 6.4 风浪二级页

| 项 | 说明 |
|----|------|
| 布局 | **重新布局**：**结构化预警报告**（多段 markdown/HTML）、**智能解读报告**（依赖 `DASHSCOPE_*` 环境变量，与现 `result`/面板一致）、**事件时间轴**（表格或时间轴组件） |
| 动作 | **跳转台风查询**：按钮使用 `window.open(url, '_blank')`（`components.html` 或 `st.link_button` 若版本支持外链新标签） |

## 7. 实时系统与离线系统的唯一差异（设计约束）

| 维度 | 离线系统 | 实时系统 |
|------|----------|----------|
| 数据入口 | 用户上传 NC（多文件） | **准实时**：占位连接器；目标为 **最新格点产品** 路径或 API 拉取后的本地镜像文件 |
| 缓冲语义 | 用户显式追加 | **自动**追加新到报文件 + FIFO；需与 `HydroInferenceService` 缓冲策略对齐 |
| UI | **完全相同**（§2～§6 共用组件） | 同上 |

实现上建议抽取 **`render_ocean_dashboard(*, mode: Literal["offline","realtime"], data_source: DataSourceAdapter)`**，避免两页复制粘贴。

## 8. 技术风险与实现选型（评审用）

| 风险 | 说明 | 缓解 |
|------|------|------|
| Streamlit 重跑模型 | 任意 widget 变更触发全页 rerun，**双视频同步与悬停暂停** 易被中断 | 涡旋/水文同屏优先 **`st.fragment`** 隔离；关键动画用 **`streamlit.components.v1.html`** |
| 原生图表能力 | `st.line_chart` 无 hover 回调 | 水文同屏 **Plotly** |
| 二级页动画 | Streamlit 无 SPA 路由动画 | Level 1 绑定 **自定义前端组件** 或接受「无动画、仅布局切换」降级 |
| 整 NC 视频耗时 | GPU/CPU 与磁盘 IO | 异步任务 + 结果轮询；首版可限制 `max_frames` 配置 |
| 新标签打开 KB | `st.button` 默认同页 | `link_button` / HTML `target=_blank` |

## 9. 建议实施顺序（不含 Level 1 时）

1. 抽取共用 `render_ocean_dashboard` 壳与 **2.1 栅格**（离线先接）。  
2. 涡旋：整 NC + 双缓冲 MP4 + FPS=1 + 时间戳条 + `st.video(autoplay)`。  
3. 水文：Plotly 单曲线轮换 + 悬停暂停 + 不足蒙层。  
4. 风浪：等级色 + 固定模板文本框。  
5. 压缩页眉与上传区。  
6. 实时页：替换数据源适配器为占位 + 与离线共用布局。  
7. **Level 1**：分别立项（抽屉、水文编辑区、风浪报告区 + 外链）。
