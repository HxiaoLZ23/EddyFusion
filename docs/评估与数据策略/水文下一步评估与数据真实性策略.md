# 水文下一步：扩展评估指标与「数据是否过假」时的对策

> 目的：在 **命题方最终评测口径未完全落地前**，用 **多类可计算指标** 更真实反映网络能力；若判断 **当前预处理使分布/物理关系失真**，则 **在可控成本下** 引入 **原始量纲评估** 或 **迭代预处理方法**。

---

## 1. 扩展评估（优先不改变数据管线）

以下均在 **现有 npz 预测与标签**（及可选 `data/processed/stats/hydro_zscore.npz` 中的 `mean/std/features`）上可做，建议在 `hydro/eval` 或离线脚本中 **追加写入 `metrics_summary` 的扩展字段**，便于与赛题表、企业材料并列。

| 方向 | 作用 | 依赖 |
|------|------|------|
| **分要素定稿** | 温盐与 u/v 分列报告，避免单一平均掩盖优劣 | 已有 per-feature 指标，材料中强制呈现 |
| **与朴素基线对比（Skill）** | 相对 persistence / 气候平均等，回答「是否比不学好」 | 需定义 **一种固定、可复现** 的基线（与窗口一致） |
| **相关系数 / 距平相关** | 侧重「型是否对」，不仅是幅值误差 | pred 与 y 同形状即可 |
| **物理量纲 RMSE/MAE** | 用 `y * std + mean` 等将 **z-score 还原** 后再算误差（°C、psu、m/s） | **必须有** 与当前数据一致的 `hydro_zscore.npz` |
| **分区或分位数统计** | 高梯度区 vs 平坦区误差，识别「只会平滑」 | 可由标签场衍生 mask |

**原则**：扩展指标 **不替代** 命题方要求；用于 **自评、答辩与是否值得加大算力的决策**。

---

## 2. 何时认为预处理「太假」或不可靠

出现 **任一** 且经交叉验证后，宜启动下一节对策（不必全满足）：

- **分布异常**：标准化后场出现大范围常数、方差趋零通道、或可视化与海洋常识严重不符（需结合 nc 抽查）。  
- **与物理矛盾**：同一片区 T/S 关系、流向与涡度一致性在还原后 **系统性违反** 可解释物理关系（需在物理空间看）。  
- **指标与直觉长期背离**：z-score 上数字「很好」但 **物理 RMSE** 或 **与基线 Skill** 无优势（说明优化目标与可用性脱节）。  
- **命题方 / 数据文档明示**：不允许某种归一化或要求 **在原始变量上** 报误差。

---

## 3. 对策 A：在原始或近原始量纲上评（优先尝试）

1. **确认统计量文件存在**：`data/processed/stats/hydro_zscore.npz`（`mean`、`std`、`features` 与 `hydro_dataset` 写出顺序一致，见 `src/preprocess/hydro_dataset.py`）。  
2. **在 eval 中**：对 `pred`、`y` 做 **逐通道反标准化** 后再算 RMSE/MAE/（可选）NRMSE（分母可用物理量 |y| 均值）。  
3. **原始 NetCDF 对照**（抽检）：同一时空点从 **未 z-score 的 nc 与反标准化后的预测** 对比，防止 npz 与 nc 脱节。

**说明**：这不等于「训练必须用原始值」；可先 **仅改评估**，成本低。

---

## 4. 对策 B：更新或分支预处理方法

仅在 A 仍不足以解释问题、或命题明确要求时启动，建议在 **新目录或新 config** 中实验，**勿覆盖** 当前可复现基线。

| 可选更新 | 说明 |
|----------|------|
| **分通道归一化策略** | u/v 单独 mean/std，或对极小方差格点单独裁剪/掩膜。 |
| **对数或鲁棒缩放** | 对重尾分量试验 `robust`/`log`（需与 `data.yaml` 及 stack 一致）。 |
| **标签与输入同源统计** | 确认 `y` 与 `x` 使用的 `mean/std` 一致（当前实现对 train 拟合后全域共用，属常规；若改须文档化）。 |
| **保留一份「未标准化副本」** | 仅用于离线评估或小规模 smoke，避免训练管道爆炸；大训练仍以工程可控方案为准。 |

任何变更须同步：**`开发阶段文档/训练与实验记录.md`**（或等价记录）、**`config/data.yaml` / 预处理命令**。

## 6. 建议执行顺序（ checklist ）

1. [ ] 在 eval 中增加 **扩展指标字段**（至少：物理 RMSE 可选、Skill 可选、分要素已固定展示）。  
2. [ ] 用同一次训练权重对 **z-score 与物理量纲** 各出一张表，对照命题沟通进展。  
3. [ ] 若物理量纲与 narrative 仍异常 → **抽查原始 nc** 与 **反标准化预测** 一致性。  
4. [ ] 若确认预处理扭曲分布 → 开 **分支预处理实验**，小数据先验证，再决定是否全量重跑。  
5. [ ] 命题方评测口径一旦下发 → **以官方脚本为准**，收敛上述自评项表述。
