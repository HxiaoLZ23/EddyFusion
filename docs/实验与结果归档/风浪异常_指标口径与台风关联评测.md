# 模块 C 指标口径与台风关联评测

> **定位**：**风浪异常识别为中心**；**台风为弱关联解释层**（IBTrACS/CMA 知识库 + 时空检索 + 可选 DTW）。  
> **不重训** LSTM 即可答辩；命题「真实台风中被正确识别的比例」在本仓库中**单独定义**，不与 MAE 混报。

---

## 1. 两层指标（必须分开写）

| 层级 | 任务 | 主指标 | 代码入口 | 能否代替命题台风 Recall |
|------|------|--------|----------|-------------------------|
| **A. 预测底座** | 空间平均 \|U10\|、SWH 的 **1 步超前**（3h）回归 | **MAE / RMSE** | `python -m src.anomaly.eval` | **否** |
| **B. 台风弱关联** | 异常时空窗 → 历史台风 **Top-K 检索** | **关联 Recall**（本仓库命名） | `scripts/anomaly_typhoon_link_eval.py` | **部分对标**（见 §3） |

## 2. 层 A：风浪回归（过程指标）

- **数据**：`data/processed/anomaly/{train,val,test}.npz`（命题年份划分见 `config/data.yaml` → `anomaly_year_split`）。
- **模型**：共享 LSTM + `wind_head` / `wave_head`；权重 `outputs/anomaly/best.pt`。
- **勿用**：无 split 的 `metrics_summary.json`（旧 `head.*` 自检可出现 MAE 风 ~4+）。

**持续性基线**（val，用窗口最后一格预测下一时刻）：

| 基线 | 风速 MAE | 波高 MAE | 平均 MAE |
|------|---------|---------|----------|
| Persistence | ~0.112 | ~0.013 | ~0.063 |
| 模型 `best.pt` | ~0.050 | ~0.009 | ~0.030 |

归档表见 [AutoDL_outputs_云端结果归档.md](AutoDL_outputs_云端结果归档.md) §6.1、`submission/tables/anomaly_metrics_val_test.md`。

**24h 补充（区域平均 rollout，非主表）**：见归档 **§6.5**、`submission/tables/anomaly_metrics_horizon24h.md`；val/test `mae_avg` ≈ **0.157 / 0.161**（持续性 ≈ 0.174 / 0.185）。

**`passed` 说明**：`src/anomaly/eval.py` 中 `mae_avg < 0.5` 仅为工程占位，**不是**赛题台风识别准确率，**不是**网上常说的 POD≥80% 达标线。

## 3. 层 B：台风关联 Recall（对标讨论）

### 3.1 与命题表述的关系

命题（`docs/架构与方法/命题方数据集说明.md`）：

> 准确率：真实发生的台风中**被正确识别**的比例

文献中同类指标多为 **Recall / POD（Probability of Detection）**，分母为 **真值台风事件数**。

本仓库**未实现**端到端「格点异常 → 自动报台风」的全链路评测；采用 **关联层 Oracle 评测** 作为可复现、可答辩的补充：

- **真值**：`typhoon_kb/events.json` 中 **测试年**（默认 **2024**，与 `anomaly_year_split.test_years` 一致）的事件；
- **系统输入**：将每个真值事件的 **起止时间 + bbox** 当作已发生的异常查询窗（**Oracle 定位**，测检索上限）；
- **命中**：`link_anomaly_to_typhoon` 的 Top-K 候选中含该 `event_id`。

记：

\[
\text{关联 Recall} = \frac{\text{命中事件数}}{\text{测试年真值事件数（过滤后）}}
\]

### 3.2 IBTrACS 关联链验收快照（2026-05-21）

本机已用 **IBTrACS v04r01** 构建 KB（`events_count=13544`），并完成测试年关联评测。**Oracle 口径**：查询时空窗 = 真值台风 bbox/时段，测 `link_anomaly_to_typhoon` 检索上限，**不是**端到端格点报警。

**表 7-3（与论文 `chatgpt稿.md` §5.5.3 一致）**

| 项目 | 数值 / 说明 |
| --- | --- |
| 事件索引 | `data/processed/anomaly/typhoon_kb/events.json` |
| 测试年 | 2024 |
| 强度过滤 | 峰值风速 ≥ 34 kt |
| Top-K | 10 |
| 真值事件数 | **84** |
| Top-K 命中数 | **84** |
| **关联 Recall** | **1.000**（84/84） |
| 解读 | 链路验收；84/84 **不可**写进摘要为「台风识别率 100%」；多数事件 `n_candidates=1` |

### 3.4 论文 / 答辩建议表述

> **主讲**：层 A 表 7-2（MAE/RMSE + 持续性基线）。**弱讲**：层 B 表 7-3（2024 年 Oracle 关联 Recall **84/84**，检索链验收）。**诚实说明未做**：LSTM 残差 → 自动时空窗 → 端到端 POD。勿将 `mae_avg≈0.03` 或 `passed` 写成台风识别率。

### 3.5 DTW 重排口径（2026-06 升级）

- **默认**：`regional_mean_obs_vs_ibtracs_center` — 异常事件窗内 **区域平均风速观测** ↔ IBTrACS **中心风速轨迹** `wind_track_mps`。
- **标准化**：两侧 z-score 后 DTW，比较**时间演化形态**；**非**严格物理匹配、**不参与** 3σ 异常判定。
- **异常窗**：默认 τ=1.5、L=2、pad=4；无连续超阈时用 peak_centered fallback（见 `app/config/demo.yaml` → `typhoon_link`）。
- **Legacy 对照**：`wind_residual_vs_ibtracs_track`（全长 |obs−pred|，默认关闭）。
- **表 6-3**：Oracle 窗 + 合成观测查询曲线，验收 KB+DTW 链路；见 `scripts/anomaly_wind_process_retrieval_stats.py`。
- **窗长统计**：`python scripts/dtw_window_fallback_stats.py` → `submission/tables/dtw_window_stats.json`。
