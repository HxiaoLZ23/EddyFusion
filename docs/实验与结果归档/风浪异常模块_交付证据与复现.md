# 模块 C（风浪异常）交付证据链与复现

面向答辩/材料：**风浪异常识别为中心**，**台风弱关联解释层**；指标分两层，勿把 MAE 写成台风识别率。口径总述见 [风浪异常_指标口径与台风关联评测.md](风浪异常_指标口径与台风关联评测.md)。

## 1. 代码与自检

| 内容 | 路径 / 命令 |
|------|-------------|
| 离线自检（双头加载 / 分级 / DTW 降级） | `python scripts/verify_module_c.py`；可选 `--run-eval-on-old` |
| 正式评估（业务口径） | `python -m src.anomaly.eval --config config/anomaly.yaml --ckpt outputs/anomaly/best.pt --split val` 与 `--split test` |
| 汇总表生成 | `python scripts/anomaly_export_metrics_table.py` |

## 2. 指标口径（两层）

### 2.1 层 A：回归（主表）

- **输出字段**（`metrics_summary_{val,test}.json`）：`mae_wind`、`mae_wave`、`mae_avg`、`rmse_wind`、`rmse_wave`、`rmse_avg`。
- **权重**：`outputs/anomaly/best.pt`，键名 **`wind_head` / `wave_head`**。
- **`passed`**：`mae_avg < 0.5` 为工程占位，**不是**命题台风 Recall。
- **旧格式 checkpoint**：仅兼容自检，MAE 很大属预期，不作业务指标。

### 2.2 层 B：台风关联 Recall（附录/答辩，弱讲）

- **脚本**：`python scripts/anomaly_typhoon_link_eval.py`（默认测试年 2024）。
- **产物**：`submission/tables/anomaly_typhoon_link_recall_2024.{json,md}`（论文 **表 7-3**）。
- **IBTrACS 快照（2026-05-21）**：Oracle 查询窗，**84/84**，Recall **1.000**；**不是**端到端 POD。
- **前提**：`build_typhoon_kb.py` 生成的 `events.json`（勿用 demo seed 写正式表）。
