# 风浪异常：典型案例对照（材料用）

用于答辩「预警案例可解释性」：每条记录对应一次**时空窗口**内的风浪异常判定与关联依据。以下为**结构模板**；数值与台风 ID 请按当次 `outputs/anomaly/` 推理或演示日志填写。

## 填写约定

| 字段 | 含义 | 来源示例 |
|------|------|----------|
| 案例编号 | 材料内引用 ID | 自建 |
| 时间窗 (UTC) | `window_hours` 对齐的序列窗口 | 数据 NPZ / 演示时间选择 |
| 区域 | 经纬度或网格索引 | 配置或 `typhoon_index` |
| MAE/残差量级 | 双头预测相对真值或 3σ 基线 | `eval` 或在线 pred vs y |
| DTW Top-k | 历史相似窗口（若有曲线） | DTW 管线输出 |
| 台风关联 | IBTrACS/CMA ID 或「无」 | `data/processed/anomaly/typhoon_index.json` |
| 报告摘要 | 结构化预警一句 | 前端/报告生成模块 |
