# 水文：其他指标评价与「能用」标准归档

> **归档日期**：2026-05-18  
> **依据**：`AutoDL/outputs` compare JSON、`hydro_l2/metrics_summary_*.json`、`src/hydro/eval.py`、`docs/实验与结果归档/AutoDL_outputs_云端结果归档.md`  
> **关联**：[水文_val_NRMSE与评测口径说明.md](水文_val_NRMSE与评测口径说明.md)（z-space vs 物理 NRMSE）

## 1. 当前在评哪些指标

| 来源 | 指标 | 用途 |
|------|------|------|
| **`src/hydro/eval.py`** | z-space **RMSE / NRMSE** 分项、**`nrmse_avg`（四通道算术平均）**、`passed`（`nrmse_avg ≤ 0.15`） | 训练选优、`metrics_summary_{val,test}.json` |
| **`hydro_cloud_assessment.py compare`** | **MAE**、RMSE(z)、NRMSE(z)、**Skill（相对持久性）**、**Pearson**、物理 RMSE（×std）、**物理 NRMSE**（传入 `hydro_zscore.npz` 时） | L0 vs L2、材料表 |

**说明**：`eval.py` 中 `passed` 依赖四通道平均 NRMSE 与 **0.15** 比较，为仓库内**粗参考**；与命题方正式口径可能不一致，且 u/v 在 z-space 下 NRMSE 易被分母放大（见 val NRMSE 说明文档）。

---

## 2. 各指标大致表现（L2 基线 + L0/eos 对比结论）

### 2.1 温盐（temp / sal）

- **Pearson ≈ 0.998**：型与真值高度一致。  
- **z-space NRMSE**：temp val 约 **0.07**、sal 约 **0.03**，分项上好看。  
- **Skill**：常为**大负**——持久性基线（复制末时刻）在温盐上极强，**不代表模型完全无效**，属指标定义与基线选择问题。

### 2.2 流场（u / v）

- **Pearson**：u 约 **0.40**、v 约 **0.53**（val），型相关弱于温盐。  
- **Skill**：相对持久性，u/v **多为正**（优于「整窗复制末时刻」），是平均 Skill 的主要正贡献。  
- **物理 RMSE**（compare）：u、v 约 **0.057～0.059 m/s**，与温盐物理 RMSE（~0.5+）相比，**并非流场物理误差比温盐大一个数量级**；z-space NRMSE 悬殊主要来自 **mean(|y|) 分母**（见 val NRMSE 文档）。

### 2.3 四通道平均与 L0 相对 L2

- **MAE_avg、NRMSE_avg（z）**：L0（含 **eos005**）相对 L2 **多数略降**。  
- **Pearson_avg**：L0 相对 L2 **略升**（约 0.73→0.74）。  
- **Skill_avg**：整体常为**负**；**仅 eos005 在 test 上** Skill 优于 L2，且 **`material_line_l0_stable_improve` = true**（MAE 与 Skill 同时优于 L2）。默认 L0（EOS=0.1）在 val/test 上 **Skill 仍不如 L2**，`material_line` 为 false。

### 2.4 L2 的 `metrics_summary` 数值锚点

| split | `nrmse_avg` | `passed` |
|-------|-------------|----------|
| val | ≈ **0.825** | false |
| test | ≈ **0.842** | false |

分项 val NRMSE（z）量级：temp ~0.07，sal ~0.03，u ~1.65，v ~1.55。

## 3.「能用」标准（分场景）

| 场景 | 结论 |
|------|------|
| **答辩 / 对比实验 / 论文叙事** | **可用**：分项 + Pearson/Skill/物理 RMSE 能说清；eos005（test）可支撑「相对 L2 的 MAE+Skill 双优」一条线。 |
| **仓库内 `eval.py` 的 `passed`** | **当前为 false**；不宜作为唯一「能用」判据。 |
| **命题方正式达标** | **须以官方评测脚本/公式为准**；自建 z-space 平均 NRMSE **不可替代**赛题结论。 |
| **生产级业务预报** | **未到**：72h 格点仍有明显误差（尤其 v 的 z-RMSE、整体 Skill 偏负），当前定位 **科研/赛题/演示**。 |
| **Streamlit / 离线大屏演示** | **可跑通链路**；新模型前 UI 默认**隐藏水文入口**（见 §5）。 |

**一句话**：多指标上 **温盐型强、流场 Skill 常为正、物理 RMSE 同量级**；**「能用」**取决于是否接受 **分项叙事 + 与 L2 对照**，而非单看四通道平均 NRMSE 或 `passed`。

---

## 4. 与「不达预期」的关系

- **内部目标**若包含「四通道平均 Skill 稳定为正」或「命题 NRMSE 硬线」→ 当前 **未完全满足**。  
- **工程决策**：在新水文模型与评测对齐完成前，**前端默认隐藏水文展示**，避免对外过度承诺；训练与 compare 脚本仍保留，便于云端迭代。

---

## 5. UI 隐藏水文：如何恢复

默认 **不展示**水文相关 Streamlit 页、总览水文 metric、离线分支「水文预测」、三模块条目中水文列、Vite 大屏水文区块与 `/l1/hydro` 路由。

**恢复展示**

| 侧 | 设置 |
|----|------|
| **Streamlit** | 启动前环境变量：`EDDYFUSION_SHOW_HYDRO=1`（或 `true` / `yes` / `on`） |
| **Vite 大屏** | 项目根 `web/.env` 或 `web/.env.development`：`VITE_SHOW_HYDRO=true`，然后 `npm run build` / `npm run dev` |

实现位置：`app/feature_flags.py`（`show_hydro_ui()`）、`web/src/featureFlags.ts`（`SHOW_HYDRO_UI`）。
