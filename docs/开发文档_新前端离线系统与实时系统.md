# 开发文档：新前端 — 离线系统与实时系统（与《规划》§2 同屏对齐）

> **文档目的**：实现 **`docs/规划_实时系统与离线系统详细设计.md`** 中的 **离线 / 实时同屏三区块** 目标态在 **Vite + React** 下的可运行版本，并接入 **FastAPI `web_api`**；本文负责 **目录、API、前端模块划分、运行方式与验收**。  
> **必读前置**：`docs/规划_实时系统与离线系统详细设计.md`（产品全文）、`docs/策略_第二套前端与水文预测热力图.md`（水文数据契约与热力图边界）、`相关文件/下一步开发方向_数据入口实时离线与大屏.md`。  
> **约束**：不修改 `src/` 评测口径；新增 Python 依赖须写入根目录 `requirements.txt`。

## 0. 《规划》原始需求摘要（撰写该规划文档时的提示词要点）

以下摘要对应生成《规划》文档时所依据的产品提示词，**实现时以《规划》正文为准**，本文仅作追溯：

1. **布局**：离线系统为 **左涡旋、右上水文、右下风浪** 同屏；**压缩标题与上传区占比**。  
2. **涡旋与单模块差异**：整 NC 视频 **FPS=1**；生成后 **自动播放**；若 NC 有时间维则在 **画面上方** 显示时间戳；**上下双画面** 同步（上无识别框、下有框）。  
3. **水文与单模块差异**：**区域均值曲线**；**约 2 秒** 轮换要素；**鼠标悬停图表则暂停轮换**；NC 缓冲不足时 **虚化** 并显示 **「数据不足，等待中」**。  
4. **第二套前端补充（策略文档）**：在同一水文区块内 **保留上述曲线行为**，并 **增加 MapLibre 地理配准预测热力图**（与曲线 **分区同显**，不得独占）。  
5. **风浪与单模块差异**：文本框上方 **醒目异常等级**（配色分级）；固定模板多行字段。  
6. **Level 1（评估后）**：涡旋 / 水文 / 风浪 **二级子页面**；悬停高亮 → 点击进入；其余折叠；**流畅动画**；各二级页内容见《规划》§6。  
7. **实时系统**：与离线 **布局与三区块行为完全一致**，仅数据源改为 **准实时 NetCDF / 最新格点产品**（接入占位：轮询 `latest` 等）。

## 3. 离线 vs 实时（工程差异）

| 维度 | 离线 | 实时 |
|------|------|------|
| **数据源条** | `multipart` 上传、`清空缓冲区`、已选数量徽标 | 状态灯、轮询间隔、`拉取 latest`、指纹与错误文案 |
| **nc_paths** | `useState` 累加上传返回的相对路径 | `useRealtimeNcFeed` 写入 `latest` 单路径 |
| **三区块 UI** | **相同组件** | **相同** |
| **水文自动刷新** | 默认关闭（用户点「加载水文数据」） | `autoLoadOnPathChange` + 5s 节流 |

## 4. FastAPI 路由（最小集）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 存活检查 |
| POST | `/api/offline/nc` | 字段 **`files`**（多文件）；返回 `{ "paths": ["app/data/nc_uploads/…"] }` |
| GET | `/api/realtime/latest` | `REALTIME_NC_POLL_DIR` 或默认上传目录下 **最新 mtime** 的 `.nc`；`path` / `fingerprint` |
| POST | `/api/hydro/heatmap` | 物化 + 推理；返回 **`lons`/`lats`/`values`** + **`curve_data`** + **`feature_names`** + `meta`（含 `T_need`/`T_hat`/`buffer_sufficient`） |
| POST | `/api/hydro/meta` | 仅缓冲步数估计 |

**安全**：路径白名单 + 禁止 `..`；见 `web_api/deps.py`。

**CORS**：`127.0.0.1:5173`、`localhost:5173`。

## 5. 前端要点

### 5.1 环境变量

| 变量 | 示例 |
|------|------|
| `VITE_API_BASE` | `http://127.0.0.1:8000` |

### 5.2 水文区块

1. `POST /api/hydro/heatmap` 成功后同时更新 **热力图栅格** 与 **`curve_data`**。  
2. **曲线区**：`setInterval` 2000ms 切换 `feature_names`；容器 `onMouseEnter` / `onMouseLeave` 控制暂停。  
3. **`meta.buffer_sufficient === false`**：曲线外包层 **opacity + blur**，叠加 **「数据不足，等待中」**；地图组件同步 `insufficient` 蒙层。  
4. **热力图区**：与曲线 **左右并排**；`mapHeight` 与左栏高度协调（如 280px）；极窄屏时整列堆叠。

### 5.3 错误展示

HTTP `detail` 字符串或 JSON 数组统一转成可读 `Error.message`。

## 6. 本地运行

**终端 1（仓库根）**

```bash
pip install -r requirements.txt
python -m uvicorn web_api.main:app --reload --host 0.0.0.0 --port 8000
```

**终端 2**

```bash
cd web
npm install
npm run dev
```

访问 **`http://127.0.0.1:5173/offline`**、**`/realtime`**。Swagger：`http://127.0.0.1:8000/docs`。
