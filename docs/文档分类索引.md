## 快速对照：写论文时优先打开顺序（示例）

1. **数据与任务**：`架构与方法/命题方数据集说明.md` → `架构与方法/NetCDF与三模块数据及训练说明.md`  
2. **方法框架**：`架构与方法/技术方案与算法说明.md` → `架构与方法/系统架构说明.md`（按需）  
3. **实验与数字**：`实验与结果归档/AutoDL_outputs_云端结果归档.md` → `实验与结果归档/水文_L2L1L0_实验归档与决策.md` / `实验与结果归档/涡旋模块工作汇总.md`  
4. **指标怎么解释**：`实验与结果归档/水文_val_NRMSE与评测口径说明.md` → `实验与结果归档/水文_其他指标与能用标准归档.md`  
5. **讨论与局限**：`过程与局限/实施过程与局限性.md` → `评估与数据策略/水文下一步评估与数据真实性策略.md`  

写**开发计划/周报**：优先 **第一节**；做**云训练/归档**：**第三节 + 第四节**。
