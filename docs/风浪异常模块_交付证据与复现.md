# 模块 C（风浪异常）交付证据链与复现

面向答辩/材料：说明指标如何产生、权重与 JSON 路径、与本仓库自检脚本的关系。

## 1. 代码与自检

| 内容 | 路径 / 命令 |
|------|-------------|
| 离线自检（双头加载 / 分级 / DTW 降级） | `python scripts/verify_module_c.py`；可选 `--run-eval-on-old` |
| 正式评估（业务口径） | `python -m src.anomaly.eval --config config/anomaly.yaml --ckpt outputs/anomaly/best.pt --split val` 与 `--split test` |
| 汇总表生成 | `python scripts/anomaly_export_metrics_table.py` |

## 2. 指标口径

- **输出字段**（写入 `metrics_summary_{val,test}.json` 的 `metrics` 内）：`mae_wind`、`mae_wave`、`mae_avg`、`rmse_wind`、`rmse_wave`、`rmse_avg`。
- **权重**：以当次训练产物 `outputs/anomaly/best.pt` 为准；需为 **新键名** `wind_head` / `wave_head`。
- **旧格式 checkpoint**：仅用于证明加载兼容；在 val 上 MAE 很大属预期，**不作为业务指标**，详见工作清单 §1.3.1。

## 3. 对外归档文件

| 类型 | 路径 |
|------|------|
| val/test 统一表（Markdown） | `submission/tables/anomaly_metrics_val_test.md` |
| 同上（CSV） | `submission/tables/anomaly_metrics_val_test.csv` |
| 典型案例对照（模板 + 填写指引） | `docs/风浪异常_典型案例对照.md` |
| eval 原始 JSON | `outputs/anomaly/metrics_summary_val.json`、`metrics_summary_test.json` |

更新流程：先跑 `eval` 生成 JSON，再跑 `anomaly_export_metrics_table.py`；最后按需填写典型案例表中的时间与字段来源。

## 4. 配置文件

- 数据与路径：`config/anomaly.yaml`（`paths.*_sequences`、`eval.metrics_file`）。
- Level：`meta.level` 与赛题档位一致，勿擅自改含义。
