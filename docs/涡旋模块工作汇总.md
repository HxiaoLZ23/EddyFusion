## 2. 数据与导出

- **命题方目录**：`服创数据集/中尺度涡识别/`，5 个 `.nc`；划分与 `src/preprocess/eddy_yolo_export.py` 内 `_EDDY_*_STEM` 一致（3 train / 1 test / 1 val）。
- **导出命令入口**：`python -m src.preprocess.eddy_dataset --export-yolo -- ...`
- **全局时间步长**：`--time-stride`（默认已改为 15；本轮公平对比若统一为 **7**，则显式 `--time-stride 7`）。
- **仅加厚 val（可选）**：`--time-stride-val <小于全局 stride 的整数>`。
- **8ch 堆叠**：加 `--stack-physics-npy`，与 PNG 同 stem 写 `*.npy`，`dataset.yaml` 含 `channels: 8`；实现见 `src/eddy/stacked_physics.py`。

**基线（3ch）示例**：

```bash
python -m src.preprocess.eddy_dataset --export-yolo -- \
  --out data/processed/eddy --data-config config/data.yaml --time-stride 7
```

**增强（8ch）示例**：

```bash
python -m src.preprocess.eddy_dataset --export-yolo -- \
  --out data/processed/eddy_enh --stack-physics-npy --time-stride 7
```

## 3. 训练与评估

- **基线训练**：`python -m src.eddy.train --config config/eddy.yaml`（或 `bash scripts/run_eddy_train.sh`）。
- **增强训练**：`python -m src.eddy.train --config config/eddy_enh.yaml`（或 `bash scripts/run_eddy_train_enh.sh`）。
- **终端无进度**：`PYTHONUNBUFFERED=1 python -m src.eddy.train ...` 或 `python -u -m ...`；仓库 `train.py` 已对非 TTY 尝试行缓冲并默认 `verbose=True`。
- **评估（val + test）**：

```bash
python -m src.eddy.eval --config config/eddy.yaml --ckpt AutoDL/outputs/eddy/best.pt --splits val,test
python -m src.eddy.eval --config config/eddy_enh.yaml --ckpt AutoDL/outputs/eddy_enh/best.pt --splits val,test
```

- **汇总表**（可选写入 `submission/tables/`）：

```bash
python scripts/eddy_write_val_test_map_table.py \
  --row baseline:AutoDL/outputs/eddy/metrics_summary_val.json:AutoDL/outputs/eddy/metrics_summary_test.json \
  --row enh8:AutoDL/outputs/eddy_enh/metrics_summary_val.json:AutoDL/outputs/eddy_enh/metrics_summary_test.json \
  --out-md submission/tables/eddy_map_val_test.md \
  --out-csv submission/tables/eddy_map_val_test.csv
```

- **已实现**：8ch **显式物理 + 频域/多尺度相关通道** 与首层卷积联合学习；推理侧频域 / TTA / geometry。

## 6. 消融对照是否有必要？

**结论：不是「必须」，取决于答辩/论文深度与时间。**

| 层级 | 是否必要 | 说明 |
|------|----------|------|
| **主对比（基线 vs 全量 8ch）** | **建议必做** | 本轮已通过 **`eval` + `metrics_summary`** 完成；这是对外主结论。 |
| **推理侧频域 / TTA（`eddy_inference_ablate`）** | **选做** | 输出的是 **检测数 / 置信度 / TTA 命中** 等，**不是 mAP**；适合「灵敏度」附录，不能替代 `eval`。 |
| **训练内逐通道消融**（例如只训 3ch 前若干物理通道） | **选做、成本高** | 需多轮训练与固定划分；仅在评委追问「哪一类通道贡献最大」时价值高。 |

**实操建议**：时间紧则 **只保留主表 + 简短文字**；若评委可能问「增强来自哪里」，可补 **1～2 组** 最小消融（例如：同数据仅关 `stack-physics-npy` 的 3ch 重训 vs 8ch，避免矩阵爆炸）。
