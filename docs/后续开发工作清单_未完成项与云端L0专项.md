### 1.3.1 旧格式 checkpoint 与指标的读法（避免误判）

- `--write-old-ckpt` / 自检里临时写出的“旧格式”权重，是对**随机初始化**模型的 `head.weight`/`head.bias` 封装；在 val 上出现 **MAE/RMSE 很大（例如 mae_avg≈5.x）** 是正常现象，只用于证明 **加载键名兼容 + eval 主链可跑通**，不表示训练效果。
- **业务/材料用指标**应以当次训练产物为准，例如 `outputs/anomaly/best.pt`（新键名：`wind_head`/`wave_head`）跑 `eval.py` 得到的 `mae_wind`、`mae_wave`、`mae_avg` 等（样例：50 epoch 训练中 `val_mse≈0.18`、`mae_avg≈0.27` 量级，以你当前 `metrics_summary_val.json` 为准）。

## 2. 专项A：云端核查预处理数据 + L0对比评估（必须优先）

## 2.1 数据真实性核查

- **脚本**：`python scripts/hydro_cloud_assessment.py audit --hydro-config <与数据一致的 yaml> --data-config config/data.yaml`（结果可 `--out-json`；本地烟测 npz 与 `hydro_hycom_*.yaml` 不一致时请改用 **`config/hydro_synthetic.yaml`** 做核查）。
- 核查文件：
  - `data/processed/hydro/*.npz`
  - `data/processed/stats/hydro_zscore.npz`
  - `data/processed/stats/hydro_preprocess_meta.json`
- 核查维度：
  - `X/y` 形状、样本数、通道顺序与 `config/hydro_*.yaml` 一致性；
  - `hydro_zscore.npz` 中 `mean/std/features` 完整性与顺序一致性；
  - 反标准化抽样统计与原始 nc 量级一致性。

## 2.2 异常触发与处理

- 触发条件（任一满足即判“有误”）：
  - 特征顺序错位、通道统计异常（如方差近 0）；
  - 反标准化后量级明显失真；
  - 数据截断/缺文件导致分布失真且不可解释。
- 处理策略：
  - 优先回退原始数据重跑预处理；
  - 若仅统计量异常，修复统计写出逻辑后重生 processed；
  - 修复产物使用新目录或完整日志，避免覆盖旧结果。

## 2.3 新增指标对比（L0 vs 基线）

- 对比对象：
  - 基线：`outputs/hydro_l2/best.pt`（或 **`AutoDL/outputs/hydro/`** 等价权重，命令行传入）
  - 创新：`outputs/hydro_l0/best.pt`
- **已实现一键对比**：见 `scripts/hydro_cloud_assessment.py compare`（MAE、RMSE、Skill vs 持久性、Pearson；可选物理尺度 RMSE）及 `docs/下一步执行清单_云端评估前端与L0优化.md` §1.5。
- 至少输出指标：
  - 分通道 MAE/RMSE；
  - Skill（相对 persistence/朴素基线）；
  - Pearson 相关系数；
  - 物理量纲误差（反标准化后 RMSE/MAE）。
- 结果产物：
  - `csv/md` 对比表；
  - 结论字段：`L0 相对基线是否稳定改进（是/否）`。

## 2.4 验收标准

- 有“数据可信/不可信”结论及证据（路径+日志）。
- 有 L0 vs 基线新增指标表。
- 若数据不可信，已完成重跑预处理与复评。

## 3. 专项B：L0 下一轮优化方案池（按成本推进）

## 3.1 低成本（先做，必须成组对照）

- 损失权重微调：
  - `loss.eos_constraint.weight`: `0.1 -> 0.03/0.05`
  - `mae_weight`: 下调或设 `0` 做对照
- AttnRes 复杂度：
  - `attn_res.num_blocks: 8 -> 4/6`
  - 调整 `attn_res.reduction` 降低过拟合与显存压力
- 训练稳定性：
  - 学习率网格：`1e-4`, `7e-5`, `5e-5`
  - 固定 seed，单轮仅改 1~2 个变量

## 3.2 中成本（低成本有效后再做）

- 通道加权损失（重点 u/v）；
- 分阶段训练（L2 收敛 -> 迁移到 L0 微调）。

## 3.3 高成本（本轮默认不进主线）

- 预处理策略迭代（分通道归一化、鲁棒缩放）并全量重跑；
- 更强物理约束（需严格反标准化与公式口径一致）。

## 3.4 方案筛选规则

- 新方案需至少在 val/test 两侧均稳定优于基线；
- 改进小但复杂度高的方案仅保留为“探索结果”，不进主交付。
